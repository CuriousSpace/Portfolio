WebSocket/STOMP Debug Console

This browser-based QA/operations console lets you test real-time channels by editing endpoint, headers, topic, destination, and payload directly.

Do not open this via file://. Use a static server. Example: python3 -m http.server 3000

Connection

Configure the WebSocket endpoint and connection options.

Subscribe

Enter a topic and subscribe or unsubscribe.

Send

Set destination and payload to send a STOMP message.

Preset

Save frequently used endpoint/topic combinations in the browser.
disconnected not subscribed
Shows STOMP debug logs, messages, websocket errors, and stomp errors with timestamps.
